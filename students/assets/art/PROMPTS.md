# Panalo Students: art prompts (bitmaps)

Each prompt below is complete: copy one block, paste it, generate, then
save the image with the **file name** above it. Send the images back and
Panalo cuts out the green, makes the web versions and drops them in.

**Where:** Gemini → Images (Nano Banana). Set the aspect ratio first:
**2:3 (portrait)** for characters, **16:9** for scenes and the wide
wallpaper, **9:16** for the tall one.
**If one is refused:** press regenerate once; if it still refuses, try
the same prompt in Google AI Studio (aistudio.google.com, the image model)
or another image tool. The prompts name no people, characters, brands or
artists, so they shouldn't trigger refusals.
**Keep the cast consistent:** after the first mascot image, attach it
when making the other three and start the prompt with "The same character
as in the attached image,". Do the same with your first student for the
other seven.
