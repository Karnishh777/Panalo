# Fonts

Served from the site (css/fonts.css). All under the SIL Open Font License
1.1 (OFL.txt). Taken from the Fontsource npm packages, version 5.3.0: Latin
subset, WOFF2.

Three roles across every look: Geist for reading and controls, Archivo
(declared wide as "Panalo Display", narrow as "Panalo Display Condensed")
for headlines, Geist Mono for numbers and time. Signal adds Doto for its
dot-matrix display.

| File | Font |
| --- | --- |
| `geist-latin.woff2`, `geist-mono-latin.woff2` | Geist and Geist Mono (variable weight), Vercel |
| `archivo-latin.woff2` | Archivo (variable width and weight), Omnibus-Type |
| `doto-latin.woff2` | Doto (variable weight), Óliver Lalan (Signal) |
